# Fonts Directory

This directory contains font files used in the TaskVerse application.

## Included Fonts

- Inter (Regular, Medium, SemiBold, Bold)

Font files need to be downloaded and placed in this directory:

- Inter-Regular.ttf
- Inter-Medium.ttf
- Inter-SemiBold.ttf
- Inter-Bold.ttf
